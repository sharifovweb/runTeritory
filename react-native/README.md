# RunTerritory GPS Paper.io 2 - React Native (Expo) Mobil Ilovasi 📱

Ushbu qism loyihaning to'liq **React Native (Expo)** versiyasidir. Android va iOS uchun **.apk** fayl chiqarish hamda smartfonlarda **Background GPS** rejimida ishlatish uchun mo'ljallangan.

---

### 🚀 Qanday Ishga Tushiriladi?

1. **Terminalda `react-native` papkasiga o'ting:**
   ```bash
   cd react-native
   ```

2. **Kutubxonalarni o'rnating:**
   ```bash
   npm install
   ```

3. **Expo dev serverni bosing:**
   ```bash
   npx expo start
   ```

4. **Telefonda Ko'rish (Expo Go):**
   - Android va iOS telefoningizga **Expo Go** ilovasini yuklab oling.
   - Terminalda chiqqan **QR-kodni** telefon kamerasi orqali skaner qiling.

---

### 📦 Android (.apk) Faylini Chiqarish (Build APK):

EAS Build orqali to'g'ridan-to mehmondor va o'rnatiladigan **.apk** fayl yaratish uchun:

```bash
npx eas build -p android --profile preview
```

Fayl avtomatik tarzda yaratiladi va sizga yuklab olish havolasi (download link) beriladi!
