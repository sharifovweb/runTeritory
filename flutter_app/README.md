# RunTerritory GPS Paper.io 2 - Flutter Mobile App 📱

Ushbu papka loyihaning to'liq **Flutter (Dart)** mobil ilova kodi hisoblanadi. Android hamda iOS qurilmalari uchun o'ta tezkor (60fps), chiroyli hamda batareya tejamkor mobil ilova hisoblanadi.

---

### 🚀 Qanday Ishga Tushiriladi?

1. **Terminalda `flutter_app` papkasiga o'ting:**
   ```bash
   cd flutter_app
   ```

2. **Kutubxonalarni yuklab oling:**
   ```bash
   flutter pub get
   ```

3. **Ulanga telefonda yoki emulyatorda ishga tushirish:**
   ```bash
   flutter run
   ```

---

### 📦 Android (.apk) Faylini Chiqarish (Build APK):

Telefonga o'rnatiladigan rasmiy **Release APK** faylini yaratish uchun terminalda bosing:

```bash
flutter build apk --release
```

Kompilyatsiya tugashi bilan o'rnatiladigan **`.apk`** fayli mana shu papkada yaratiladi:
📍 **`flutter_app/build/app/outputs/flutter-apk/app-release.apk`**
